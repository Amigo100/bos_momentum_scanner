# Sterling Grid — Input & Source Map (Tier 3d, V9)

> Tier 3d consumes the completed deep-dive work for one confirmed BUY and emits an HTML article — not a
> card. It introduces nothing new, and renders what the analytical tiers produced (the adapt-to-output
> rule). Below: the input contract, then the section→source map so every section traces to upstream work.

---

## INPUT — the confirmed-BUY dossier (all already in the chain)
```
· Tier-3a dossier   discriminator scorecard (4 signals: present/partial/absent) · ≥4x drivers (verified
                    numbers) · survival picture (+ KS-3 / Yartseva reads where 3a computed them) ·
                    positioning & tension · comparable-winner read (peaks + time-to-peak) · bear
                    landscape · archetype
· Tier-3b geometry  decoupled floor (method) + target (methods-used range) · four scenarios
                    (bear/base/re-rate/overshoot) + probs · re-rating velocity (t-to-rerate, IRR,
                    P(≥2x@6/12/18mo)) · what's priced in + steelman · catalyst window · bear classifications
· Tier-3c verdict   BUY · type (multibagger/great trade) · conviction (Extremely Bullish/Bullish) ·
                    expected path + target + horizon + driver · the comprehensive memo
· Tier-4 decision   confirmed BUY + the opportunity read (theme/inflection/catalyst/reward/risk; vs RKLB-2024)
· LINEAGE           Macro · Theme · Mapping · Triage · Gate · [Consensus] · Evidence · Geometry · Verdict · Decision
```
No new web, no new model — a missing fact is named as an open question.

## Theme-confirmation read → V9 provenance
- **dual-confirmed** — on the Tier-0 top-down map *and* surfaced bottom-up (Tier-1 NEW-CLUSTER) or
  confirmed by Tier-2.5 consensus.
- **catalog-gap** — a Tier-1 NEW-CLUSTER the top-down map hadn't named yet.
- **top-down-only** — on the map, exposure adjacent / peripheral.

## OUTPUT
The complete self-contained **HTML article** (house design system; 2,500–3,500 words) → written to the
deep-dive output path (e.g. `articles/<ticker>-deep-dive.html`).

## Handoff
The article is the **weekly newsletter's** deep-dive ("Tuesday deep dive") and the **source for the
notes'** signal companions.
