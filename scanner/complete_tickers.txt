# COMPLETE US STOCK UNIVERSE
# ===========================
# 
# This file should contain ~3000 US stock tickers for comprehensive scanning.
# The scanner will calculate beta for all tickers and filter to Beta >= 1.8.
#
# HOW TO GET A COMPLETE LIST:
# ---------------------------
#
# Option 1: Export from Finviz (FREE)
#   1. Go to https://finviz.com/screener.ashx
#   2. Set filters: Exchange = NYSE, NASDAQ, AMEX
#   3. Click "Export" (bottom right) - downloads CSV
#   4. Copy ticker column here (one per line)
#
# Option 2: Export from TradingView
#   1. Go to https://www.tradingview.com/screener/
#   2. Filter: Country = USA, Type = Stock
#   3. Export to CSV, copy tickers here
#
# Option 3: Download from GitHub datasets
#   Search for "US stock tickers list" on GitHub
#   Many free datasets available
#
# FORMAT:
# -------
# - One ticker per line (preferred)
# - Or comma-separated: AAPL, MSFT, GOOGL
# - Lines starting with # are ignored
# - Case insensitive (will be uppercased)
#
# EXAMPLE:
# --------
# AAPL
# MSFT
# GOOGL
# AMZN
# META
# ...
#
# After adding tickers, run:
#   python universe_builder.py --force
#
# This will:
#   1. Download 1-year price data for all tickers
#   2. Calculate beta vs SPY for each
#   3. Filter to Beta >= 1.8
#   4. Save to scan_universe.txt (~400-600 high-beta stocks)
#
# Rebuild weekly or when you update this file.
